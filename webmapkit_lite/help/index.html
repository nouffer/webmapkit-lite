Web Map Kit Lite

Publish your QGIS project as a fast, shareable web map on your own free Cloudflare storage.

The full guide is online: mapship.link/webmap-kit/guide

1. Set up hosting (once)

  1. Click the Web Map Kit Lite icon on the Web toolbar, then Hosting.
  2. Create a free Cloudflare account if you don't have one, and switch on R2 (Cloudflare asks for a card; the free tier costs nothing).
  3. Click the link to create a token, paste it back, and the plugin sets up the rest.

2. Publish a map

  1. Style your project in QGIS as usual and zoom to where visitors should start.
  2. Click the icon, check the title, layers and Web address, and click Create web map.
  3. Copy the link or open it. To update the map later, publish again with the same web address: the link stays the same.

Supported styles

Single symbol, categorized, graduated and proportional (size assistant) symbols, labels from one field, field aliases, hidden fields and layer transparency. Other styles are shown in one colour, and the finish screen tells you.

Costs and limits

  • Cloudflare R2's free tier includes 10 GB of storage and no bandwidth fees.
  • Published maps are public to anyone with the link.
  • To remove a map, delete its folder in Cloudflare: R2 → your bucket → the folder with the map's web address.

Web Map Kit (full edition)

Adds photos in popups, your own domain (maps.yourcompany.com), a list of all your published maps (open, embed, update, delete) and removes the "Made with Web Map Kit" link: mapship.link/webmap-kit
