# Web Map Kit Lite

Free QGIS plugin: publish your QGIS project as a fast, shareable web map to your own free Cloudflare R2 storage.
No server, no subscription, no coding.

- Vector tiles (one PMTiles file) with a MapLibre viewer that keeps your QGIS styling:
  single, categorized, graduated and proportional symbols, labels, field aliases and hidden fields
- Popups, legend with layer toggles and transparency, search, phone-friendly layout
- One click to publish; publishing again with the same web address updates the map at the same link
- Maps show a small "Made with Web Map Kit" link

**Web Map Kit (full edition)** adds photos in popups, your own domain (maps.yourcompany.com), a list of all your
published maps (open, copy embed code, update, delete) and no badge: https://mapship.link/webmap-kit/

## Install
QGIS → Plugins → Manage and Install Plugins → search "Web Map Kit Lite".
Guide: https://mapship.link/webmap-kit/guide/
